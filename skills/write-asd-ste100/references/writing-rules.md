# ASD-STE100 Writing Rules

Use this checklist with the official ASD-STE100 Issue 9 standard. This checklist does not replace the standard or its controlled dictionary.

## Vocabulary

- Use an approved word only with its approved meaning and part of speech.
- Use only the approved forms of verbs and adjectives.
- Use American English spelling.
- Use a technical noun or technical verb only when the subject field or project approves the term.
- Select technical terms that are short and easy to understand.
- Do not use slang, jargon, or regional words as technical terms.
- Use the same technical term for the same item or concept.
- Do not use a technical noun as a verb unless the term is also an approved technical verb.
- Do not make an unapproved phrasal verb from approved words.

## Verbs and voice

- Use the infinitive, imperative, simple present, simple past, or simple future tense.
- Use a past participle as an adjective only when Issue 9 permits that form.
- Do not use auxiliary verbs to make complex verb constructions.
- Use an `-ing` form only as an approved word, a technical noun, or a technical noun modifier.
- Use the active voice.
- In descriptive text, use the passive voice only when the agent is unknown.
- Use an approved verb, not a noun, to describe an action.

## Sentences and paragraphs

- Write one topic in each sentence.
- Use no more than 20 words in a procedural sentence.
- Use no more than 25 words in a descriptive sentence.
- Use a vertical list for complex text.
- Put related information in one paragraph.
- Put only one topic in each paragraph.
- Use no more than six sentences in one paragraph.
- Do not use a semicolon.
- Make each pronoun reference clear.

Issue 9 has special word-count rules. Parenthetical text, quoted text, identifiers, headings, abbreviations, and specified number-unit groups each count as one word.

## Procedures

- Write one instruction in each sentence.
- Combine actions only when the actions occur at the same time.
- Write instructions in the imperative form.
- Put a necessary condition before the instruction.
- Put a comma between the condition and the instruction.
- Put steps in the required sequence.
- Use a note only for information.
- Do not put an instruction, requirement, or limit in a note.

## Descriptions

- Give information gradually.
- Use key words and key phrases to make the structure clear.
- Do not use the imperative form in descriptive text.
- Explain concrete behavior and results. Do not use abstract or ambiguous statements.

## Safety instructions

- Identify each safety instruction as a warning or caution.
- State the hazard or possible result.
- Put a necessary condition before the required action.
- Keep the instruction near the applicable step.
- Do not change controlled safety text without approval from its owner.

## Review checklist

1. Compare the final document with the source.
2. Confirm that all facts, requirements, limits, and conditions are unchanged.
3. Verify each general word in the Issue 9 dictionary.
4. Verify each technical term in authoritative project material.
5. Check the sentence, paragraph, voice, and procedure rules.
6. Record each necessary exception.
7. Set the correct review status.
